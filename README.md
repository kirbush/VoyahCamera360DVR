# VoyahCamera360DVR

Просмотр и запись видеопотока камер Voyah Free на головном устройстве Android. Минималистичный интерфейс подходит для отдельного запуска и встраивания окна приложения в VoyahTweaks.

**[Скачать APK 0.3-alpha](artifacts/Voyah-Camera-0.3.apk)** · [Архитектура и совместимость](docs/ARCHITECTURE.md) · [Тестирование](docs/TESTING.md)

## Возможности

- Автоматическое открытие видеопотока при запуске.
- Просмотр выбранного ракурса без области кругового обзора либо полного составного изображения.
- Ручная запись и остановка с сохранением MP4/H.264 без звука. Остановка записи сохраняет просмотр.
- Автозапись по выбору в настройках; по умолчанию выключена.
- Сохранение настроек видеовхода, ракурса и формата изображения.
- Переключение переднего и заднего ракурса через штатный сервис автомобиля — экспериментальная функция, требующая существующего `su`.

Настройки открываются шестерёнкой справа сверху, переключение ракурса находится слева сверху, запись и стоп — снизу. Ролики сохраняются в `Movies/VoyahCameraLab`. При отсутствии новых кадров приложение показывает сообщение и завершает текущую запись. При скрытии окна камера освобождается; потеря фокуса видимого окна не закрывает просмотр.

## Совместимость и ограничения

Целевая система — Voyah Free H97X, V3 Restyling российской сборки, Sport Plus, Android 11 / API 30. Совместимость с другими моделями и версиями прошивки не подтверждена. На исследованном ГУ ранее исправлялась геометрия AVM-буфера на уровне HAL; APK не устанавливает это исправление и не гарантирует работу на неизменённой прошивке.

Версия **alpha**. Просмотр и запись проверены на целевой системе; выполнение нового переключателя ракурса из APK, запуск после сна и перезагрузки, встраивание в VoyahTweaks и работа в движении требуют дополнительной проверки.

Camera2 ID `1` предоставляет составной AVM-поток с выбранным ракурсом. Номера видеовходов не соответствуют передней и задней физическим камерам. Одновременная независимая запись передней и задней камер не реализована.

Просмотр и запись используют разрешение `CAMERA`. Для переключения ракурса требуется уже доступный `su` и совпадение системных файлов с поддерживаемой версией. Приложение не устанавливает root. Переключатель не зависит от VoyahTweaks или Frida. При недоступном переключении остаётся просмотр текущего потока.

Это Android Activity, которую можно встраивать средствами лаунчера, а не `AppWidgetProvider`. Фоновая запись, циклическое удаление файлов и разбиение записи на сегменты не реализованы. Приложение не изменяет сигналы скорости; доступность камер в движении пока не установлена.

## Установка

Скачайте APK по ссылке выше, установите его на совместимое ГУ и разрешите доступ к камере. Обновление поверх существующей установки требует одинаковой подписи APK.

Через ADB в PowerShell:

```powershell
./scripts/Install.ps1 -Launch
```

Activity для встраивания: `local.codex.voyahcameralab/.MainActivity`.

## Сборка

Требуются JDK 17 и Android SDK с пакетами `platforms;android-30`, `build-tools;35.0.0`, `ndk;27.2.12479018`. Gradle Wrapper включён; версии Gradle и Android Gradle Plugin закреплены.

```sh
./gradlew :app:corePolicyTest :app:assembleDebug
```

Windows: `gradlew.bat :app:corePolicyTest :app:assembleDebug`. Результат: `app/build/outputs/apk/debug/app-debug.apk`. Путь SDK задаётся через Android Studio, `ANDROID_HOME` или локальный `local.properties`. При отдельном размещении NDK используйте `AVM_NDK_DIR` или `-PavmNdkDir=...`.

Тест скомпилированного ARM64-кода формирования запросов:

```sh
python -m pip install unicorn==2.1.4
python scripts/test_native_protocol.py /path/to/ndk/27.2.12479018
```

GitHub Actions запускает проверки и собирает APK приложения и тестов. Debug APK из CI подписан отдельным ключом и может не устанавливаться поверх скачанного из `artifacts/` APK.

Для сборки с собственным ключом задайте `VOYAH_SIGNING_KEYSTORE`, при необходимости `VOYAH_SIGNING_STORE_PASSWORD`, `VOYAH_SIGNING_KEY_ALIAS` (по умолчанию `cameralab`) и `VOYAH_SIGNING_KEY_PASSWORD`. Ключи и пароли не должны попадать в Git.
