# VoyahCamera360DVR

Камеры Voyah Free H97X (V3 Restyling, RU Sport Plus), Android 11/API 30. Минимальный экран для просмотра, в том числе внутри окна приложения в VoyahTweaks: поток открывается при запуске, настройки спрятаны под шестерёнкой справа сверху.

**[APK 0.3 для вечернего теста](artifacts/Voyah-Camera-0.3.apk)** · [План проверки](docs/EVENING-TESTS.md) · [Что подтверждено](EVIDENCE.md)

На основном экране: переключение ракурса слева, запись и стоп снизу, настройки справа. Запись по умолчанию **не включается**. В настройках можно включить «Начинать запись при открытии», выбрать видеовход, сохранённый ракурс и обрезку вида сверху. Стоп завершает MP4 и оставляет просмотр. Видео без звука: `Movies/VoyahCameraLab`.

При отсутствии новых кадров приложение показывает сообщение; текущая запись завершается. Возврат кадров убирает сообщение. При скрытии окна камера освобождается. Простая потеря фокуса видимого окна не закрывает просмотр.

## Статус

- Интерфейс, автопросмотр, ручная запись/стоп, сохранение настроек и окно 600×320 проверены на ГУ в версии 0.2. MP4 12,13 секунды полностью декодирован без ошибок.
- **Одна прямая команда переключила задний ракурс на передний при закрытом штатном 360.** Это подтверждено до отключения ноутбука. Имитация нажатия на скрытое окно не работала.
- В 0.3 эту команду отправляет отдельный ARM64 helper через уже имеющийся `su`. Выполнение helper из APK, обратное переключение, работа после сна/перезагрузки и совместимость со штатными камерами **ожидают вечерней проверки**. Проверка пакетов и сборка выполнены офлайн.
- Источник Camera2 **1** — составной AVM с выбранным ракурсом, а не независимая физическая камера. Входы 0, 2, 3 в отдельных тестах не дали кадров. Одновременная запись перед/зад не реализована.
- Отключение потока на скорости пока гипотеза. Скорость и блокировки автомобиля приложение не подменяет.

Просмотр и запись используют обычное разрешение CAMERA. Для переключения перед/зад нужен существующий `su`; приложение не устанавливает root, не патчит прошивку и не зависит от VoyahTweaks/Frida. Helper принимает только две фиксированные команды. Для другой версии системных файлов переключение отключено до проверки совместимости; текущий видеопоток остаётся доступен.

Это Activity для встраивания средствами Твикс, не Android AppWidgetProvider. Непрерывная фоновая запись, циклическое удаление файлов и готовый двухканальный регистратор в эту версию не входят.

## Сборка

Android Studio или JDK 17 + Android SDK: `platforms;android-30`, `build-tools;35.0.0`, `ndk;27.2.12479018`. Gradle Wrapper включён. Версии AGP/Gradle закреплены; [совместимость AGP 8.7](https://developer.android.com/build/releases/agp-8-7-0-release-notes).

```sh
./gradlew :app:corePolicyTest :app:assembleDebug
```

Windows: `gradlew.bat :app:corePolicyTest :app:assembleDebug`. APK: `app/build/outputs/apk/debug/app-debug.apk`. SDK задаётся через Android Studio, `ANDROID_HOME` или игнорируемый `local.properties`. При отдельном размещении NDK можно задать `AVM_NDK_DIR` или `-PavmNdkDir=...`.

```sh
python -m pip install unicorn==2.1.4
python scripts/test_native_protocol.py /path/to/ndk/27.2.12479018
```

Тест эмулирует фактически скомпилированный ARM64-код кодирования двух запросов; к автомобилю не подключается. `corePolicyTest` проверяет геометрию, временные метки, поздние callback и обнаружение пропавших кадров.

## Подпись и обновление

APK в `artifacts/` подписан прежним локальным ключом разработки и предназначен для обновления текущей установки. Ключа в Git нет. Обычный Gradle/CI создаёт debug APK с **другим** ключом: он не установится поверх текущего без прежнего ключа либо удаления старой установки.

Для локального обновления задайте `VOYAH_SIGNING_KEYSTORE`, при необходимости `VOYAH_SIGNING_STORE_PASSWORD`, `VOYAH_SIGNING_KEY_ALIAS` (по умолчанию `cameralab`) и `VOYAH_SIGNING_KEY_PASSWORD`. Не сохраняйте ключи в репозитории. CI проверяет сборку и прикладывает свой debug APK как workflow artifact.

Детальные логи, исходные кадры, пользовательские видео и бинарники производителя в Git не включены. Лицензия проекта — [MIT](LICENSE).
