# APK

`Voyah-Camera-0.4.apk` — alpha-сборка версии `0.4-alpha` с опциональным масштабированием верхних 60% кадра для проверки потока с зелёным низом. Предыдущая сборка `Voyah-Camera-0.3.apk` сохранена для сравнения. Контрольная сумма последней сборки находится в `SHA256SUMS`.

Просмотр и запись рассчитаны на систему, указанную в основном README. Переключение ракурса из приложения остаётся экспериментальным; ограничения описаны в [документации](../docs/ARCHITECTURE.md).

APK подписан ключом разработки, не включённым в репозиторий. Debug APK из GitHub Actions использует другой ключ. Для обновления без удаления приложения подписи должны совпадать.
