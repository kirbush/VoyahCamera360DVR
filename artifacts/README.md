# Evening test APK

`Voyah-Camera-0.3.apk` is signed with the pre-existing local development key for an in-place update on the tested head unit. It is an offline-built evening-test version. Native front-selection encoding was demonstrated on-device; the new application's helper path and reverse selection need the checks in `docs/EVENING-TESTS.md`.

This small APK is intentionally tracked for direct download. Toolchains, signing keys, device videos and vendor binaries are not included. CI artifacts use a separate debug signing key.
