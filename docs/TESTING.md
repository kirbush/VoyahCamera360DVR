# Тестирование

## Автоматические проверки

```sh
./gradlew :app:corePolicyTest :app:assembleDebug :app:assembleDebugAndroidTest
python -m pip install unicorn==2.1.4
python scripts/test_native_protocol.py /path/to/ndk/27.2.12479018
```

JVM-проверки охватывают геометрию кадра, временные метки, устаревшие callback и обнаружение остановки потока. Native-тест эмулирует скомпилированный ARM64-код запросов и проверяет отклонение неподдерживаемых значений; к автомобилю он не подключается.

## Проверки на ГУ

Проводите действия с интерфейсом на стоящем автомобиле в P, без запуска парковочного манёвра. Фиксируйте версию прошивки и SHA-256 APK вместе с результатами.

1. Открытие без предварительного запуска штатного 360: поток появляется, запись по умолчанию выключена. Если активация штатного 360 необходима, отметить это отдельно.
2. Передний → задний → передний при скрытом штатном 360: проверить фактическую сцену и сохранённый ракурс при повторном открытии. При недоступном `su` проверить сообщение и сохранение просмотра.
3. Ручная запись не менее 20 секунд → стоп: файл воспроизводится, просмотр продолжается. Отдельно проверить включение и отключение автозаписи в настройках.
4. Опция «Убрать зелёный низ»: на подходящем источнике исчезает нижний заполнитель, сохраняются верх и низ полезной сцены и правильные пропорции в просмотре и MP4. Проверить сохранение опции после перезапуска и возврат к полному кадру после её отключения. Полный составной кадр и обрезка вида сверху: правильные пропорции, нет зелёной области или потери полезного изображения.
5. Встраивание Activity в VoyahTweaks: маленькое окно, доступность кнопок, сохранение потока при потере фокуса и освобождение камеры после скрытия окна.
6. Передача камеры между приложением, штатным 360 и парковщиком: отсутствие зависаний и конкурирующих повторных захватов.
7. Сон, пробуждение и полный перезапуск ГУ: восстановление просмотра и сохранение настроек.

Для пассивной проверки доступности потока в движении запись и логи включаются заранее. Водитель не взаимодействует с экраном или ноутбуком. Сопоставьте стоянку, движение и остановку: скрытие штатного окна, прекращение callback, ошибка Camera2 и замороженное содержимое буферов — разные симптомы. Изменение сигналов скорости в процедуру не входит.

## Сбор диагностики

Используйте `scripts/Capture.ps1`: режим `Start` начинает сбор, `Mark` добавляет отметку, `Stop` завершает сбор, `Pull` загружает данные. Для загрузки роликов добавьте `-IncludeVideos` к `Pull`. Параметры перечислены в начале скрипта.

Данные сохраняются в игнорируемой папке `diagnostics/`. Перед публикацией отчёта удаляйте персональные данные и сведения автомобиля. Не коммитьте исходные логи или видео в репозиторий.
